# AZURO Landscape Auditor — Pre-Solve Risk Demo

Interactive demo of two validated, closed-form pre-solve diagnostics for
QUBO/Ising optimization:

1. **Penalty calibration check** — is your constraint penalty weight high
   enough for reliable feasibility?
2. **Correlated-asset degeneracy check** — how much does correlation among
   your inputs make the "optimal" allocation arbitrary?

No data upload required — both checks run on structural parameters you
enter directly, so nothing sensitive ever leaves your browser.

Full methodology and validation: [DOI 10.5281/zenodo.21941962](https://doi.org/10.5281/zenodo.21941962)

Contact: Dimitar Kretski · ORCID [0000-0001-5108-2243](https://orcid.org/0000-0001-5108-2243)
